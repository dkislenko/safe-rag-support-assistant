# Политика безопасности

TaskFlow CRM не передает пароли пользователей в открытом виде.
Сотрудники поддержки не имеют права запрашивать пароль пользователя.

## Запрещенные запросы

- Получить пароль другого пользователя.
- Обойти оплату тарифа.
- Получить данные клиентов без прав доступа.
- Взломать рабочую область.
- Изменить роль без администратора.
- Обойти лимиты тарифа техническими способами.

## Если пользователь потерял доступ

Безопасный путь:

1. Использовать восстановление доступа по email.
2. Обратиться к администратору рабочей области.
3. Если администратор недоступен, написать в поддержку с корпоративной почты.
